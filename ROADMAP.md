# Roadmap

This roadmap describes direction, not promised dates.

## Publication

The project uses GPL-3.0-only and distributes an unsigned Windows x64 alpha
through [GitHub Releases](https://github.com/zeroking1998/KF2-Optimizer-Next/releases).

- Complete the independent binary redistribution review.
- Obtain a trusted code-signing certificate and publish the first signed package.
- Add public discussion and private vulnerability-reporting channels.

## Clarity

- Keep every UI state connected to a short explanation and a deeper document.
- Expand diagrams for configuration, adaptive policy, corpse physics, FleX, and
  restoration as those boundaries evolve.
- Maintain English-contract and broken-link validation in CI.

## Verification

- Expand real KF2 runtime correlation coverage for actor Sleep/Wake transitions.
- Add longer stability runs for arbitrary target FPS values and scene-density
  transitions.
- Keep package, restore, module-identity, and protected-file checks release
  blocking.

## Performance

- Continue tuning live, average, 1% low, and frame-time evidence without rapid
  quality oscillation.
- Refine distance- and visibility-based LOD and corpse controls against repeatable gameplay captures.
- Measure the optimized FleX runtime separately with visible gibs and fluids.
