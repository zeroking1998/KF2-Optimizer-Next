# Glossary

**1% low FPS** — The FPS equivalent of the slowest one percent of measured
frames. It highlights repeated stutter that an average can hide.

**Acknowledgement / receipt** — Provider evidence that a specific requested
action reached a known result.

**Active corpse** — A dead actor that is still performing relevant cosmetic
physics work.

**Adaptive** — Policy that selects bounded settings from measurements and
context instead of using one fixed preset.

**Applied** — Confirmed by matching acknowledgement or verified readback. It
does not mean merely requested.

**Capability** — Proof that the correct provider, authority, target,
acknowledgement, and restoration path exist for one control.

**Corpse ceiling** — User-selected maximum permitted dead-body count. The
runtime budget may be lower, never higher.

**Distance Sleep** — A confirmed request to permanently stop expensive
cosmetic simulation for an eligible corpse after it crosses the active
distance threshold. The selected maximum bounds the corpse pool, while Distance
Sleep itself adds no separate actor limit.

**FleX** — NVIDIA particle/physics technology used by an optional, protected
laboratory path in this project.

**Passthrough** — The optimizer has released control and leaves the native
provider behavior unchanged.

**PresentMon** — The third-party telemetry component used to observe presentation
timing. It retains its own license.

**Proposed** — Selected by policy but not yet confirmed as applied.

**Ragdoll Sleep** — An actor-scoped request to stop redundant active ragdoll
simulation, confirmed by a matching receipt.

**Readback** — A second observation used to verify the effective value after a
write or runtime request.

**Zed Time** — KF2 slow motion. It is explicit policy context because normal
time and distance behavior cannot be assumed during slow motion.
