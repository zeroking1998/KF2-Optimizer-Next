# Issue 72 product matrix

This matrix applies Issue 72 to the new portable, external KF2 Optimizer. It
does not claim compatibility with the historical product architecture.

## Permanent safety boundary

The production path does not inject code, read unknown process memory, install
a driver, bypass anti-cheat/security, or infer gameplay values from unrelated
telemetry. A requested offline hook is treated as an integrated, explicitly
selected laboratory mode. It may become writable only after exact ABI checks
and isolated stability evidence; every mismatch remains pass-through or blocked.
